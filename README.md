# Sales Performance Dashboard – Power BI

Interactive executive dashboard analyzing sales performance across branches, product categories, and customers using a multi-table invoice dataset.

## Overview
This project transforms raw sales and invoice data into an executive-level dashboard, surfacing key performance indicators and actionable insights for business decision-making.

## Key Metrics
- Total Sales: EGP 228.4K
- Total Profit: EGP 38.5K
- Operating Profit Margin: 16.9%

## Analysis Included
- Sales distribution by branch
- Sales mix by product category
- Profitability analysis by category
- Top 5 customers by sales value
- Top 3 best-selling products
- Geographic sales distribution by city

## Key Insights
- Nasr City and Mohandessin branches account for ~63% of total sales across the four branches.
- Computers and smartphones are the main profit drivers for the business.

## Recommendations
- Improve sales performance in Alexandria and Giza branches
- Introduce bundled offers combining computers, phones, and accessories
- Launch a loyalty program for top customers
- Focus inventory on high-profitability categories

## Tools Used
- Power BI (data modeling, DAX, interactive dashboarding)
- Excel (data preparation)
